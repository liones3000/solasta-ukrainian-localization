# Українська локалізація для Solasta: Crown of the Magister

Це фанатський мод української локалізації для Solasta: Crown of the Magister. 
(_Мав версію без доповнень, тому і не перекладав їх_.)

> Це мій перший досвід з перекладу гри на Unity і з такою кількістю тексту.

Поточна версія перекладу є робочою і придатною для проходження.

У грі дуже великий обсяг тексту: інтерфейс, описи предметів, здібностей, заклять, монстрів, журнал завдань, репліки, навчальні підказки та службові рядки.
У поточній версії `uk.tsv` містить `32.747 тис. рядків`.

Переклад був створений за допомогою локальних мовних моделей:

`mistral-small-3.2-24b + lapa-v0.1.2 (Українська LLM з відкритим кодом)`

Я використовував 2 мови: `англійська + німецька` для кращого перекладу, вийшло непогано. Але є деякі проблеми, бо ці моделі не ідеально перекладають українською.

Після цього приблизно 15% тексту було відредаговано вручну, тож є що виправляти.

**Мод замінює англійську мову в грі на українську. Тобто для використання української локалізації в налаштуваннях гри потрібно вибрати English.**

## Встановлення

1. Встановіть Unity Mod Manager для Solasta.
2. Скопіюйте папку `UkrainianLocalization` у папку `Mods` гри.

Приклад правильного шляху:

`C:\Program Files (x86)\Steam\steamapps\common\Slasta_COTM\Mods\UkrainianLocalization`

У папці мода мають бути файли:

```text
- UkrainianLocalization.dll
- Info.json
- uk.tsv
- source_review.tsv
- README_UA.txt
```

3. Запустіть гру.
4. У налаштуваннях гри виберіть мову `English`.
5. Англійський слот буде замінений українським перекладом.

---

## Як редагувати переклад

Основний файл перекладу `uk.tsv`:

Формат:
`KEY	Український текст`

Приклад:

```text
Action/&AttackTitle	Атака
MainMenu/&NewAdventureTitle	Нова пригода
```

Не змінюйте `KEY`.
Редагуйте тільки текст після табуляції.

---

## Файл для вичитки

Файл:

```text
source_review.tsv
```

містить український переклад і витягнуті оригінальні тексти іншими мовами для порівняння.

Формат:

```text
KEY	UK	EN	DE	FR
```

Цей файл потрібен тільки для зручної вичитки. Гра його не читає.

Якщо хочете виправити переклад:

1. Знайдіть потрібний рядок у `source_review.tsv`.
2. Подивіться оригінальний текст англійською, німецькою або французькою.
3. Знайдіть той самий `KEY` у `uk.tsv`.
4. Виправте український текст у `uk.tsv`.
5. Збережіть файл у кодуванні UTF-8.

## Важливі символи, які не можна видаляти

У текстах можуть бути службові маркери гри. Їх потрібно залишати без змін.

Приклади:

```text
{0}
{1}
{2}
\n
\t
<sprite index={11}>
<color=...>
</color>
<size=...>
</size>
<b>
</b>
[i2p_...]
```

Якщо видалити або змінити такі маркери, текст у грі може відображатися неправильно або зламати частину інтерфейсу.

Приклад правильного перекладу:

```text
EN: Add {0} dice to the effect.
UK: Додати {0} куб. до ефекту.
```

## Про українські символи та шрифти

У Solasta стандартні ігрові шрифти не містять повної підтримки української кирилиці. Через це без додаткового виправлення українські літери можуть відображатися як квадратики.

Мод автоматично додає fallback-шрифт із системних шрифтів Windows. Він шукає один із таких шрифтів:

```text
Segoe UI
Arial
Calibri
Tahoma
Verdana
NotoSans
```

На звичайній Windows 10/11 ці шрифти зазвичай уже встановлені, тому українські літери мають працювати автоматично.

---

## Якщо у грі квадратики замість українських літер

У Solasta стандартні ігрові шрифти не мають повної підтримки української кирилиці. Через це українські літери можуть відображатися як квадратики.

Мод намагається автоматично використати один із системних шрифтів Windows:

```text
Segoe UI
Arial
Calibri
Tahoma
Verdana
```

На звичайній Windows 10/11 ці шрифти зазвичай уже встановлені, тому український текст має працювати автоматично.

---

### Що зробити, якщо квадратики залишаються

1. Повністю закрийте гру й запустіть її знову.
2. Переконайтесь, що мод увімкнений у Unity Mod Manager.
3. Переконайтесь, що файл `uk.tsv` лежить у папці мода поруч із `UkrainianLocalization.dll`.
4. Перевірте, чи у Windows встановлені шрифти `Segoe UI` або `Arial`.

У Windows це можна перевірити тут:

```text
Settings → Personalization → Fonts
```

або:

```text
C:\Windows\Fonts
```

---

### Який шрифт встановити, якщо потрібного немає

Рекомендований легальний варіант — встановити `Noto Sans`. 
> Також можна знайти потрібні шрифти, але це на ваш розсуд - бо це сіра зона.

Це безкоштовний шрифт від Google з широкою підтримкою різних мов і символів, включно з українською кирилицею.

Щоб встановити шрифт у Windows:

1. Завантажте `Noto Sans` з Google Fonts.
2. Розпакуйте архів, якщо він завантажився як `.zip`.
3. Натисніть правою кнопкою на файл `.ttf` або `.otf`.
4. Оберіть `Install` або `Install for all users`.
5. Повністю перезапустіть гру.

Також можна встановити шрифт через:

```text
Settings → Personalization → Fonts
```

і перетягнути туди файл шрифту.

---

### Чи можна просто замінити українські літери схожими латинськими або іншими символами?

Я пробував такий варіант: наприклад, замінювати частину українських символів на схожі аналоги, щоб уникнути квадратиків.

Але це виглядає погано й читається з дискомфортом. Український текст стає неприродним, частина слів виглядає зламаною, а довгі описи читати неприємно.

Тому в моді використовується інший підхід: нормальні українські символи залишаються як є, а мод додає fallback-шрифт для їх відображення.

## Linux, Steam Deck і Proton

Мод створювався й тестувався насамперед для Windows.

На Linux, Steam Deck або через Proton усе може працювати інакше, бо гра запускається у Proton/Wine-середовищі, а доступ до системних шрифтів може відрізнятися від Windows.

Якщо у вас Linux / Steam Deck / Proton і замість українських літер квадратики:

1. Спробуйте встановити шрифт `Noto Sans` (або взяти/знайти інші вказані шрифти) у систему.
2. Перезапустіть Steam і гру.
3. Якщо це не допомогло, можливо, шрифт треба додати саме в Proton/Wine prefix гри.
4. Для цього досвідчені користувачі можуть використовувати інструменти на кшталт Protontricks / Winetricks.

Підтримка Linux / Steam Deck / Proton поки не гарантується. Якщо ви змогли запустити мод і виправити шрифти на Steam Deck або Linux, будь ласка, поділіться способом — це допоможе додати точну інструкцію для інших гравців.

## Чому на початку іноді видно англійський текст

Мод спочатку підключає український fallback-шрифт, а вже потім підміняє текст на український. Це зроблено спеціально, щоб не показувати квадратики замість українських літер.

Тому під час запуску гри частина раннього завантаження або перші секунди меню можуть бути англійською. Після 1–3 секунд текст має оновитися на український.

---

## Якщо гра просить вимкнути моди

Solasta може попереджати, що для деяких сюжетних сцен потрібно вимкнути моди. Навіть якщо цей мод лише змінює локалізацію, технічно він усе одно є runtime-модом.

Якщо після переходу до сюжетної сцени гра зависає на нескінченному завантаженні:

1. Закрийте гру.
2. Вимкніть мод в Unity Mod Manager.
3. Запустіть гру.
4. Пройдіть проблемну сцену.
5. Збережіть гру після сцени.
6. Закрийте гру.
7. Увімкніть мод назад.

---

## Як повернути англійську мову

Оскільки мод замінює англійський мовний слот, для повернення оригінальної англійської потрібно:

* вимкнути мод у Unity Mod Manager; або
* тимчасово прибрати/перейменувати файл `uk.tsv`; або
* видалити папку мода.
